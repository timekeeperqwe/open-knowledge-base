## 推荐的协作流程

注：该方案由AI友情提供

以后每次开始写文档时，建议按照这个顺序操作：

1. git pull —— 获取同学最新修改。
2. 编辑 .tex 文件。
3. 本地编译检查是否正常。
4. git add .
5. git commit -m "描述本次修改"
6. git push

这样可以大幅减少冲突和覆盖彼此修改的风险。
